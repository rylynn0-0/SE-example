## 二、逐个文件怎么写

### 2.1 `index.html` —— 3 行有效代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>待办清单</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

拆开看：

| 小组件 | 写什么 | 为什么 |
|---|---|---|
| 文档声明 | `<!DOCTYPE html>` | 告诉浏览器这是 HTML5 |
| 挂载点 | `<div id="app"></div>` | 空节点，等 Vue 往里渲染 |
| 入口脚本 | `<script type="module" src="/src/main.js">` | Vite 从这里开始编译 |

**语法点**：`id="app"` 是普通 HTML id；`type="module"` 表示按 ES Module 加载脚本。

**易错**：`src` 写成相对路径 `src/main.js` 会 404，必须 `/src/main.js`。

### 2.2 `package.json` —— 4 个字段

```json
{
  "name": "todo-frontend",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview --port 4173"
  },
  "dependencies": {
    "axios": "^1.7.7",
    "element-plus": "^2.7.8",
    "vue": "^3.4.38",
    "vue-router": "^4.4.5"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.1.4",
    "vite": "^5.4.9"
  }
}
```

拆开看：

| 小组件 | 作用 | 可以改吗 |
|---|---|---|
| `name` / `private` / `type` | 项目名、禁止发布、ES Module | 一般不动 |
| `scripts` | 命令别名：`npm run dev` → `vite` | 可加命令 |
| `dependencies` | 运行时要用的包 | 加库时在这 |
| `devDependencies` | 只在开发/构建时用的包 | 加构建工具时在这 |

**语法点**：JSON 键必须双引号、**不能写注释**；`^1.7.7` 表示允许同大版本内升级。

**易错**：把 `vite` 放进 `dependencies` 不影响运行，但会让生产安装多装构建工具；反之把 `vue` 放进 `devDependencies`，生产构建会失败。

### 2.3 `vite.config.js` —— 3 块配置

```js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

const BACKEND = 'http://localhost:8080'

export default defineConfig({
  plugins: [vue()],

  server: {
    host: '0.0.0.0',
    port: 5173,
    proxy: {
      '/api':         { target: BACKEND, changeOrigin: true },
      '/doc.html':    { target: BACKEND, changeOrigin: true },
      '/webjars':     { target: BACKEND, changeOrigin: true },
      '/v3/api-docs': { target: BACKEND, changeOrigin: true },
      '/swagger-ui':  { target: BACKEND, changeOrigin: true }
    }
  },

  build: { outDir: 'dist', sourcemap: false }
})
```

拆开看：

| 小组件 | 作用 | 常用改法 |
|---|---|---|
| `plugins: [vue()]` | 让 Vite 认识 `.vue` 文件 | 一般不动 |
| `server.host` / `server.port` | 开发服务器监听地址/端口 | 端口冲突时改 |
| `server.proxy` | 把 `/api` 等前缀转发给后端 | 后端换端口改 `BACKEND` |
| `build.outDir` | 构建产物目录 | 默认 `dist` |

**语法点**：`import` 具名导入 `defineConfig`、默认导入插件；`export default` 默认导出配置对象；`proxy` 是对象字面量，键是路径前缀。

**易错**：`proxy` 只在 `npm run dev` 生效。生产环境由 Nginx 转发，改这里不影响 Docker（见 [09 必要技术](09-必要技术.md) §5.3）。

### 2.4 `src/main.js` —— 3 个动作

```js
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import zhCn from 'element-plus/es/locale/lang/zh-cn'

import App from './App.vue'
import router from './router'
import './styles/global.css'

const app = createApp(App)               // ① 创建

app.use(ElementPlus, { locale: zhCn })   // ② 装插件
app.use(router)

app.mount('#app')                        // ③ 挂载
```

拆开看：

| 小组件 | 作用 | 依赖 |
|---|---|---|
| 导入区 | 引入 Vue、组件库、样式、根组件、路由 | 路径要对 |
| `createApp(App)` | 创建应用实例 | 必须传根组件 |
| `app.use(...)` | 安装插件 | 插件必须先 import |
| `app.mount('#app')` | 渲染到 `index.html` 的节点 | id 必须匹配 |

**语法点**：`import 'xxx.css'` 只执行不取值（引入样式）；`app.use(插件, 配置)` 的第二个参数是全局配置。

**易错**：少 `app.use(router)` → `<router-view>` 不被识别，白屏；少 `element-plus` 样式 → 组件没有外观。

### 2.5 `src/App.vue` —— 2 个区块

```vue
<script setup>
// 外壳不需要业务逻辑
</script>

<template>
  <div class="layout">
    <!-- ① 页头 -->
    <header class="header">
      <h1>待办清单</h1>
      <a href="/doc.html" target="_blank">接口文档 ↗</a>
    </header>

    <!-- ② 内容区 -->
    <main class="main">
      <router-view />
    </main>
  </div>
</template>

<style scoped>
.header { display: flex; justify-content: space-between; padding: 16px 24px; }
.main { padding: 20px 24px; }
</style>
```

拆开看：

| 小组件 | 作用 | 关键点 |
|---|---|---|
| `<header>` | 页头：标题 + 文档链接 | 链接用相对路径 `/doc.html`，由代理转发 |
| `<router-view />` | 内容区：当前路由的页面渲染在这 | 必须已 `app.use(router)` |
| `<style scoped>` | 只作用于本组件的样式 | 不要写全局样式 |

**语法点**：SFC 三段结构（script / template / style）；模板**只能有一个根节点**（这里是 `div.layout`）。

**易错**：把业务写在 `App.vue` 里 → 以后加页面要改外壳；`<router-view>` 写成 `<router-view />` 后忘了注册路由。

### 2.6 `src/router/index.js` —— 3 块

```js
import { createRouter, createWebHistory } from 'vue-router'
import TodoView from '../views/TodoView.vue'

// ① 路由表
const routes = [
  { path: '/', name: 'todo', component: TodoView, meta: { title: '待办清单' } },
  { path: '/:pathMatch(.*)*', redirect: '/' }
]

// ② 路由实例
const router = createRouter({
  history: createWebHistory(),
  routes
})

// ③ 全局钩子
router.afterEach((to) => {
  document.title = to.meta?.title ? `${to.meta.title} · 待办清单` : '待办清单'
})

export default router
```

拆开看：

| 小组件 | 作用 | 关键点 |
|---|---|---|
| `routes` 数组 | 一条路由 = 一个对象 | `path` 是访问地址，`component` 是页面 |
| 兜底路由 | `/:pathMatch(.*)*` | 乱输地址重定向回首页 |
| `createRouter` | 创建实例 | `history: createWebHistory()` 决定 URL 无 `#` |
| `afterEach` | 跳转后执行 | 改标签页标题 |

**语法点**：数组 + 对象字面量；`to.meta?.title` 可选链；`redirect: '/'` 跳转。

**易错**：history 模式上线后刷新 404 —— 需要 Nginx `try_files`（见 09 §5.3）；加页面时忘记加路由 → 访问不到。

### 2.7 `src/api/request.js` —— 4 块

```js
import axios from 'axios'
import { ElMessage } from 'element-plus'

// ① 实例
const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// ② 请求拦截器
request.interceptors.request.use(
  (config) => config,
  (error) => Promise.reject(error)
)

// ③ 响应拦截器：成功分支
request.interceptors.response.use(
  (response) => {
    const body = response.data

    // 非统一格式（静态资源等）原样返回
    if (body === null || typeof body !== 'object' || body.code === undefined) {
      return body
    }
    if (body.code === 200) {
      return body.data
    }
    ElMessage.error(body.message || '请求失败')
    return Promise.reject(new Error(body.message))
  },

  // ④ 响应拦截器：失败分支
  (error) => {
    ElMessage.error(error.response?.data?.message || '网络异常，请确认后端已启动')
    return Promise.reject(error)
  }
)

export default request
```

拆开看：

| 小组件 | 作用 | 什么时候改 |
|---|---|---|
| 实例 | 统一 `baseURL`、超时 | 后端前缀变了改这里 |
| 请求拦截器 | 发请求前加 token/头 | 加登录时 |
| 响应成功分支 | 拆 `{code,message,data}` 外壳 | 后端响应结构变了改这里 |
| 响应失败分支 | 网络错误统一提示 | 提示文案 |

**语法点**：

| 写法 | 含义 |
|---|---|
| `axios.create({...})` | 创建带默认配置的实例 |
| `interceptors.response.use(成功, 失败)` | 注册拦截器；**返回什么，`await` 就得到什么** |
| `body.code === undefined` | 判断字段不存在（容错非统一格式） |
| `Promise.reject(new Error(...))` | 主动抛错，让调用方进 `catch` |
| `error.response?.data?.message` | 可选链逐层取 |

**易错**：拦截器里 `return body.data` 之后，页面再写 `.data` 就是 `undefined`；失败分支忘了 `return Promise.reject`，错误会被吞掉，页面以为成功。

### 2.8 `src/api/task.js` —— 6 个函数

```js
import request from './request'

export function pageTasks(params) {
  return request.get('/tasks', { params })          // GET /api/tasks?...
}

export function createTask(data) {
  return request.post('/tasks', data)               // POST /api/tasks
}

export function updateTask(id, data) {
  return request.put(`/tasks/${id}`, data)          // PUT /api/tasks/{id}
}

export function toggleTask(id) {
  return request.patch(`/tasks/${id}/finished`)     // PATCH /api/tasks/{id}/finished
}

export function deleteTask(id) {
  return request.delete(`/tasks/${id}`)             // DELETE /api/tasks/{id}
}

export function getStats() {
  return request.get('/tasks/stats')                // GET /api/tasks/stats
}
```

拆开看：

| 函数 | 对应后端 | 参数放哪 |
|---|---|---|
| `pageTasks` | `@GetMapping` | `{ params }` → URL 查询串 |
| `createTask` | `@PostMapping` | 第二参数 → 请求体 |
| `updateTask` | `@PutMapping("/{id}")` | 路径拼 id + 请求体 |
| `toggleTask` | `@PatchMapping("/{id}/finished")` | 只拼路径 |
| `deleteTask` | `@DeleteMapping("/{id}")` | 只拼路径 |
| `getStats` | `@GetMapping("/stats")` | 无参数 |

**语法点**：`export function` 具名导出；`` `/tasks/${id}` `` 模板字符串插值；`{ params }` 是对象字面量的简写（等价 `{ params: params }`）。

**易错**：路径写成 `/api/tasks` → 与 `baseURL` 拼成 `/api/api/tasks`，404。

### 2.9 `src/views/TodoView.vue` —— 11 个小组件

这个文件最大，**不要整段读**，按下面 11 块分别看。每块都可以单独理解、单独改。

#### 2.9.1 导入区

```js
import { onMounted, reactive, ref } from 'vue'
import { ElMessage, ElMessageBox } from 'element-plus'
import { createTask, deleteTask, getStats, pageTasks, toggleTask, updateTask } from '../api/task'
```

| 导入 | 用来做什么 |
|---|---|
| `onMounted` | 页面挂载后加载数据 |
| `reactive` / `ref` | 声明响应式数据 |
| `ElMessage` | 成功/失败提示 |
| `ElMessageBox` | 删除二次确认 |
| `api/task.js` 的六个函数 | 调后端 |

---

#### 2.9.2 列表状态（`ref`）

```js
const loading = ref(false)     // 表格加载遮罩
const list = ref([])           // 当前页数据
const total = ref(0)           // 总条数

const query = reactive({       // 查询条件（对应后端 TaskQuery）
  pageNum: 1,
  pageSize: 5,
  keyword: '',
  finished: null               // null=全部
})

const stats = reactive({       // 统计卡片（对应后端 TaskStats）
  total: 0,
  finished: 0,
  unfinished: 0,
  fromCache: false,
  ttl: 0
})
```

拆开看：

| 数据 | 类型 | 为什么用这个 |
|---|---|---|
| `loading` / `list` / `total` | `ref` | 会被**整体替换**（`list.value = data.records`） |
| `query` / `stats` | `reactive` | 只改字段（`query.pageNum = 2`） |

**语法点**：`ref` 脚本里要 `.value`；`reactive` 直接改字段；模板里都不用 `.value`。

**易错**：`list` 用 `reactive([])` 后整体赋值会丢响应式；`query` 用 `ref({})` 也能用，但模板里要写 `query.pageNum`，容易和 `.value` 混淆。

---

#### 2.9.3 弹窗与表单状态

```js
const dialog = reactive({ visible: false, saving: false, id: null })
const formRef = ref()

const form = reactive({
  title: '',
  description: '',
  priority: 2,
  dueDate: null
})

const rules = {
  title: [
    { required: true, message: '请输入任务标题', trigger: 'blur' },
    { max: 100, message: '标题不能超过 100 个字符', trigger: 'blur' }
  ]
}
```

| 小组件 | 作用 |
|---|---|
| `dialog.visible` | 弹窗开关 |
| `dialog.saving` | 保存按钮 loading |
| `dialog.id` | `null` = 新增，有值 = 编辑 |
| `formRef` | 拿到 `el-form` 实例，调 `validate()` |
| `rules` | 声明式校验规则 |

**语法点**：`ref()` 不传值 = `undefined`，需要时 `formRef.value?.validate()`；校验规则是对象数组。

**易错**：漏 `prop="title"` → 规则不生效；`validate()` 失败会 reject，必须 `.catch`。

#### 2.9.4 数据加载：`loadList`

```js
async function loadList() {
  loading.value = true
  try {
    const data = await pageTasks({ ...query })
    list.value = data.records
    total.value = Number(data.total)
  } finally {
    loading.value = false
  }
}
```

拆开看：

| 行 | 作用 |
|---|---|
| `loading.value = true` | 打开遮罩 |
| `{ ...query }` | 复制一份参数，避免被后续修改影响 |
| `data.records` | 后端分页对象的当前页数据 |
| `Number(data.total)` | 后端返回数字，防御性转换 |
| `finally` | 成功失败都关遮罩 |

**易错**：只在 `try` 里关 loading → 请求失败界面永远转圈。

---

#### 2.9.5 数据加载：`loadStats` 与 `loadAll`

```js
async function loadStats() {
  const data = await getStats()
  Object.assign(stats, data)     // 把返回字段合并进响应式对象
}

async function loadAll() {
  try {
    await Promise.all([loadList(), loadStats()])   // 并发请求
  } catch (e) {
    // 错误提示已由拦截器统一弹出
  }
}
```

| 小组件 | 作用 | 关键点 |
|---|---|---|
| `loadStats` | 拉统计数字 | `Object.assign` 保留响应式，不能 `stats = data` |
| `loadAll` | 同时刷新列表 + 统计 | `Promise.all` 并发，少一半等待 |

**易错**：`stats = await getStats()` 会替换掉 `reactive` 对象，页面不更新。

#### 2.9.6 搜索与分页

```js
function handleSearch() {
  query.pageNum = 1        // 必须回第 1 页
  loadList()
}

function onPageChange(page) {
  query.pageNum = page
  loadList()
}

function onSizeChange(size) {
  query.pageSize = size
  query.pageNum = 1        // 每页条数变了，页码越界
  loadList()
}
```

| 触发 | 调用 | 为什么要重置页码 |
|---|---|---|
| 点「查询」/回车 | `handleSearch` | 否则第 3 页搜索结果可能为空 |
| 点页码 | `onPageChange` | 不需要重置 |
| 改每页条数 | `onSizeChange` | 否则可能越界 |

**模板里怎么绑**：

```vue
<el-input v-model="query.keyword" @keyup.enter="handleSearch" />
<el-button @click="handleSearch">查询</el-button>
<el-pagination
  :total="total" :page-size="query.pageSize" :current-page="query.pageNum"
  @current-change="onPageChange" @size-change="onSizeChange" />
```

**易错**：`@click="handleSearch()"` 会在页面加载时执行一次；`:total` 不传分页算不出页数。

---

#### 2.9.7 新增与编辑：`openCreate` / `openEdit`

```js
function openCreate() {
  dialog.id = null
  Object.assign(form, { title: '', description: '', priority: 2, dueDate: null })
  dialog.visible = true
  formRef.value?.clearValidate()
}

function openEdit(row) {
  dialog.id = row.id
  Object.assign(form, {
    title: row.title,
    description: row.description ?? '',
    priority: row.priority ?? 2,
    dueDate: row.dueDate ?? null
  })
  dialog.visible = true
  formRef.value?.clearValidate()
}
```

拆开看：

| 小组件 | 作用 |
|---|---|
| `dialog.id = null` / `row.id` | 一个变量区分新增/编辑 |
| `Object.assign(form, {...})` | 回填表单，保留 `form` 响应式 |
| `clearValidate()` | 清掉上次打开的红色校验提示 |
| `??` | 后端字段可能为 null，给默认值 |

**易错**：`Object.assign(form, row)` 会把 id、finished 等也塞进表单，提交时多带字段；应显式挑字段。

#### 2.9.8 保存：`handleSave`

```js
async function handleSave() {
  const valid = await formRef.value.validate().catch(() => false)
  if (!valid) return                 // 校验不过就中断

  dialog.saving = true
  try {
    if (dialog.id) {
      await updateTask(dialog.id, { ...form })   // 编辑
    } else {
      await createTask({ ...form })              // 新增
    }
    ElMessage.success('保存成功')
    dialog.visible = false
    await loadAll()                  // 重新拉列表和统计
  } finally {
    dialog.saving = false
  }
}
```

拆开看：

| 步骤 | 作用 | 关键点 |
|---|---|---|
| `validate().catch(() => false)` | 触发校验 | 失败转成 `false`，不抛异常 |
| `if (!valid) return` | 校验不过就停 | 不发请求 |
| `{ ...form }` | 复制表单数据 | 避免直接传响应式对象 |
| `loadAll()` | 刷新页面数据 | 后端已清缓存，重新拉才一致 |
| `finally` | 关 saving | 成功失败都执行 |

**易错**：不 `await validate()` → `valid` 是 Promise，永远为真；保存后不刷新 → 列表还是旧数据。

---

#### 2.9.9 删除与切换：`handleDelete` / `handleToggle`

```js
async function handleDelete(row) {
  try {
    await ElMessageBox.confirm(`删除「${row.title}」？`, '提示', { type: 'warning' })
  } catch {
    return                          // 用户点「取消」
  }
  await deleteTask(row.id)
  ElMessage.success('删除成功')

  // 删掉当前页最后一条时，页码回退，避免空白页
  if (list.value.length === 1 && query.pageNum > 1) {
    query.pageNum -= 1
  }
  await loadAll()
}

async function handleToggle(row) {
  await toggleTask(row.id)          // 只发请求，不先改本地状态
  await loadAll()                   // 以后端返回为准
}
```

拆开看：

| 小组件 | 作用 | 关键点 |
|---|---|---|
| `ElMessageBox.confirm` | 二次确认 | 取消会 reject，必须 catch |
| 页码回退 | 避免删完变空白页 | 判断「当前页只剩 1 条」 |
| `handleToggle` | 切换状态 | 界面以数据库为准，不乐观更新 |

**易错**：`confirm` 不 catch → 点取消时控制台报未捕获异常；开关用 `v-model` 会先改界面，请求失败后状态对不上。

#### 2.9.10 初始化：`onMounted`

```js
onMounted(loadAll)
```

| 写法 | 含义 |
|---|---|
| `onMounted(loadAll)` | 挂载完成后执行一次 |
| `onMounted(() => loadAll())` | 等价写法 |

**易错**：直接在 `<script setup>` 顶层调用 `loadAll()` 也能跑，但组件未挂载时就开始请求，语义不对，也不方便测试。

#### 2.9.11 模板区：5 个区块

模板按页面结构分成 5 块，每块对应上面的函数：

**① 统计卡片**

```vue
<div class="stats">
  <div>总数：{{ stats.total }}</div>
  <div>未完成：{{ stats.unfinished }}</div>
  <div>已完成：{{ stats.finished }}</div>
</div>
```

| 语法 | 含义 |
|---|---|
| `{{ stats.total }}` | 插值：显示数据 |

**② 工具栏**

```vue
<div class="toolbar">
  <el-input v-model="query.keyword" placeholder="搜索标题" @keyup.enter="handleSearch" />
  <el-select v-model="query.finished" clearable placeholder="全部状态" @change="handleSearch">
    <el-option label="未完成" :value="0" />
    <el-option label="已完成" :value="1" />
  </el-select>
  <el-button type="primary" @click="handleSearch">查询</el-button>
  <el-button type="primary" @click="openCreate">新增</el-button>
</div>
```

| 语法 | 含义 |
|---|---|
| `v-model` | 输入框 ↔ `query.keyword` 双向绑定 |
| `@keyup.enter` | 回车触发搜索 |
| `@change` | 下拉变化即搜索 |
| `:value="0"` | 选项值是数字 0（冒号） |

**③ 表格**

```vue
<el-table v-loading="loading" :data="list" stripe>
  <el-table-column prop="id" label="ID" width="70" />
  <el-table-column prop="title" label="标题" />

  <el-table-column label="状态" width="90">
    <template #default="{ row }">
      <el-switch :model-value="row.finished === 1" @change="handleToggle(row)" />
    </template>
  </el-table-column>

  <el-table-column label="操作" width="140">
    <template #default="{ row }">
      <el-button link @click="openEdit(row)">编辑</el-button>
      <el-button link type="danger" @click="handleDelete(row)">删除</el-button>
    </template>
  </el-table-column>
</el-table>
```

| 语法 | 含义 |
|---|---|
| `:data="list"` | 动态绑定数据源（冒号） |
| `v-loading="loading"` | 加载遮罩 |
| `prop="title"` | 直接显示字段 |
| `#default="{ row }"` | 自定义列插槽，`row` 是当前行 |
| `:model-value="row.finished === 1"` | 开关状态由数据决定 |
| `@change="handleToggle(row)"` | 切换时传当前行 |

**④ 分页**

```vue
<el-pagination
  background
  layout="total, sizes, prev, pager, next"
  :total="total"
  :page-size="query.pageSize"
  :current-page="query.pageNum"
  :page-sizes="[5, 10, 20]"
  @current-change="onPageChange"
  @size-change="onSizeChange" />
```

| 属性/事件 | 含义 |
|---|---|
| `layout` | 显示哪些部分 |
| `:total` | 总条数（算页数用） |
| `:page-size` / `:current-page` | 当前每页条数 / 页码 |
| `@current-change` / `@size-change` | 换页 / 换条数 |

**⑤ 弹窗与表单**

```vue
<el-dialog v-model="dialog.visible" :title="dialog.id ? '编辑' : '新增'" width="520px">
  <el-form ref="formRef" :model="form" :rules="rules" label-width="90px">
    <el-form-item label="标题" prop="title">
      <el-input v-model="form.title" />
    </el-form-item>
    <el-form-item label="截止日期">
      <el-date-picker v-model="form.dueDate" type="date" value-format="YYYY-MM-DD" />
    </el-form-item>
  </el-form>
  <template #footer>
    <el-button @click="dialog.visible = false">取消</el-button>
    <el-button type="primary" :loading="dialog.saving" @click="handleSave">保存</el-button>
  </template>
</el-dialog>
```

| 语法 | 含义 |
|---|---|
| `v-model="dialog.visible"` | 弹窗开关双向绑定 |
| `:title="dialog.id ? '编辑' : '新增'"` | 三元决定标题 |
| `:model` / `:rules` / `prop` | 表单校验三要素 |
| `ref="formRef"` | 拿到表单实例 |
| `value-format="YYYY-MM-DD"` | 日期以字符串保存，和后端对齐 |
| `#footer` | 底部插槽 |

**易错**：日期不写 `value-format` → 传给后端是 ISO 字符串，`LocalDate` 解析失败；`prop` 和 `rules` 的键不一致 → 校验不触发。

**拼起来的结构**（2.9.1–2.9.11 按这个顺序组装）：

```
<script setup>
  导入 ........................ 2.9.1
  列表状态 ..................... 2.9.2
  弹窗/表单状态 ................ 2.9.3
  loadList .................... 2.9.4
  loadStats / loadAll ......... 2.9.5
  handleSearch / 分页 .......... 2.9.6
  openCreate / openEdit ....... 2.9.7
  handleSave .................. 2.9.8
  handleDelete / handleToggle . 2.9.9
  onMounted ................... 2.9.10
</script>

<template>
  ① 统计卡片 ................... 2.9.11
  ② 工具栏
  ③ 表格
  ④ 分页
  ⑤ 弹窗与表单
</template>
```

## 三、这一章用到的语法（汇总）

### 3.1 Vue 模板指令

| 写法 | 作用 | 例子 |
|---|---|---|
| `{{ 值 }}` | 显示数据 | `{{ stats.total }}` |
| `:属性="值"` | 动态绑定 | `:data="list"` |
| `@事件="函数"` | 事件 | `@click="handleSave"` |
| `v-model="值"` | 双向绑定 | `v-model="query.keyword"` |
| `v-if` / `v-else` | 条件渲染 | `v-if="list.length"` |
| `v-for` | 循环 | `v-for="i in list" :key="i.id"` |
| `#default="{ row }"` | 插槽 | `el-table` 自定义列 |
| `#footer` | 具名插槽 | 弹窗底部按钮 |

### 3.2 Vue 脚本

```js
import { ref, reactive, computed, onMounted } from 'vue'

const list = ref([])              // 基本类型/数组/对象
list.value = data.records         // 脚本里 .value

const query = reactive({ pageNum: 1 })
query.pageNum = 2                 // 对象直接改字段

const count = computed(() => list.value.length)

onMounted(() => { loadAll() })
```

### 3.3 异步与 Promise

```js
async function load() {
  try {
    const data = await pageTasks({ ...query })
    list.value = data.records
  } finally {
    loading.value = false
  }
}

await Promise.all([loadList(), loadStats()])
```

### 3.4 Axios

```js
request.get('/tasks', { params: { pageNum: 1 } })   // → /tasks?pageNum=1
request.post('/tasks', { title: 'abc' })            // 请求体
request.put(`/tasks/${id}`, data)
request.patch(`/tasks/${id}/finished`)
request.delete(`/tasks/${id}`)
```

| 区别 | `params` | 第二个参数（请求体） |
|---|---|---|
| 变成 | URL 查询串 | JSON 请求体 |
| 后端收 | 对象绑定 / `@RequestParam` | `@RequestBody` |

## 六、前端最常见的 6 个错

| 现象 | 原因 | 解决 |
|---|---|---|
| 白屏 | `index.html` 的 `src` 路径错，或 `main.js` 报错 | 看控制台第一个红色错误 |
| `<el-table>` 不渲染 | 忘了 `app.use(ElementPlus)` | 检查 `main.js` |
| 界面不更新 | 数据没用 `ref`/`reactive` 包 | 改用响应式 |
| 点按钮没反应 | 写成 `@click="handleSearch()"` | 去掉括号（除非要传参） |
| 搜索无效但不报错 | 字段名和后端不一致 | 见 [04 前端与后端耦合](04-前端与后端耦合.md) §4 |
| 请求 404 | `baseURL` 与后端前缀不一致 | 两边都写 `/api` |
