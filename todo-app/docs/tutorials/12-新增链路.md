# 12 · 增：填表单 → 保存 → 新行出现

> **一句话**：点新增 → `openCreate` → 填表单 → `handleSave` → `createTask` →
> `POST /api/tasks` → Controller → Service → `INSERT` → 清缓存 → 回查 →
> 关闭弹窗 → `loadAll` → 新行出现。
>
> 公共部分见 [10 总览](10-增删改查总览.md)。
> 代码里的 `//` 是中文解释，写在代码后面；新手先读注释，再读代码。

---

## 一、先看流程

```
点「＋ 新增任务」
  → openCreate()
  → dialog.id = null，form 重置，dialog.visible = true
  → 用户填写 form
  → 点「保存」
  → handleSave()：validate → dialog.saving = true
  → createTask({ ...form })
  → POST /api/tasks
  → TaskController.create
  → TaskServiceImpl.createTask
  → INSERT INTO t_task ...
  → clearStatsCache() 删除 todo:stats
  → getById(id) 查回完整数据
  → Result.ok(Task) → JSON
  → 关闭弹窗 → loadAll()
  → 列表多一行、统计数字变化
```

## 二、打开弹窗：先把状态清干净

`TodoView.vue:179-185`：

```js
function openCreate() { // 点“＋ 新增任务”时执行
  dialog.id = null // null 表示“新增”；有 id 才是编辑
  Object.assign(form, { title: '', description: '', priority: 2, dueDate: null }) // 把表单恢复成初始值
  dialog.visible = true // 打开弹窗
  formRef.value?.clearValidate() // 清掉上一次留下的红色校验提示
}
```

表单字段（`TodoView.vue:67-72`）：

```js
const form = reactive({ // 表单数据；属性变了页面会跟着变
  title: '',        // 标题，必填
  description: '',  // 备注，可以不填
  priority: 2,      // 优先级：1 低，2 中，3 高；默认中
  dueDate: null     // 截止日期，可以不选
})
```

日期选择器要写 `value-format="YYYY-MM-DD"`，这样 `form.dueDate` 是字符串，
和后端 `LocalDate` 的 `yyyy-MM-dd` 对得上。

## 三、保存：先校验，再提交

`TodoView.vue:209-230`（新增分支节选）：

```js
async function handleSave() { // 点“保存”时执行
  const valid = await formRef.value.validate().catch(() => false) // 触发校验；失败转 false
  if (!valid) return // 校验不过，直接结束，不发请求

  dialog.saving = true // 保存按钮转圈，防止用户连点
  try { // 提交新增
    await createTask({ ...form }) // 把表单复制一份发给后端
    ElMessage.success('新增成功') // 成功后弹绿色提示
    dialog.visible = false        // 关闭弹窗
    await loadAll()               // 重新查列表和统计
  } finally { // 收尾：一定停转圈
    dialog.saving = false // 不管成功失败，都停止按钮转圈
  }
}
```

两个细节：

- `validate()` 不通过就直接 `return`，连请求都不发。
- `dialog.saving` 绑到保存按钮的 `:loading`，防止连点出两条。

## 四、请求：POST 一个 JSON

`api/task.js:40-42`：

```js
export function createTask(data) { // 新增接口封装

```

请求体（JSON 不能写注释，字段说明看下面表格）：

```json
{
  "title": "复习软件工程",
  "description": "",
  "priority": 2,
  "dueDate": "2026-11-15"
}
```

| 字段 | 意思 |
|---|---|
| `title` | 标题，必填 |
| `description` | 备注，可空 |
| `priority` | 1 低 / 2 中 / 3 高 |
| `dueDate` | 截止日期，格式 `yyyy-MM-dd` |

没有 `id`、`finished`、`createTime`、`updateTime`，这些由后端/数据库生成。

## 五、后端：补默认值 → 入库 → 清缓存 → 回查

`TaskController.java:102-109`：

```java
@PostMapping // 处理 POST /api/tasks
public Result<Task> create(@RequestBody Task task) { // 把请求体 JSON 转成 Task 对象
    if (!StringUtils.hasText(task.getTitle())) { // 标题是 null、空串或空格
        return Result.fail(400, "任务标题不能为空"); // 业务失败，code=400，给前端提示
    }
    return Result.ok(taskService.createTask(task)); // 校验通过，交给 Service
}
```

`TaskServiceImpl.java:175-194`：

```java
@Transactional(rollbackFor = Exception.class) // 出异常时回滚数据库操作
public Task createTask(Task task) { // 返回新增后的完整任务
    if (task.getPriority() == null) task.setPriority(2); // 没传优先级，默认 2（中）
    if (task.getFinished() == null) task.setFinished(0); // 新任务默认未完成

    this.save(task); // INSERT，数据库生成 id 后回填到 task.id
    clearStatsCache(); // 统计数字变了，删掉 Redis 统计缓存
    return this.getById(task.getId()); // 再查一次，补上 create_time / update_time
}
```

为什么要 `getById` 再返回？
因为 `save` 只回填了 `id`，`createTime/updateTime` 是数据库默认值生成的，
不重新查这两个字段就是 `null`。

## 六、实际 SQL

```sql
INSERT INTO t_task (title, description, priority, finished, due_date) -- 只写有值的列；没写的 create_time/update_time/deleted 用数据库默认值
VALUES (?, ?, ?, ?, ?); -- ? 是参数占位符，不是把用户输入拼进 SQL
```

- `id` 由 `AUTO_INCREMENT` 生成，JDBC 会把它回填给 Java 对象。
- 参数化 SQL 能防 SQL 注入。

## 七、回显：关弹窗，重新查一遍

```js
dialog.visible = false // 关闭弹窗
await loadAll()        // 同时刷新列表和统计
```

`loadAll` 会同时刷新列表和统计：

- 列表按 `finished ASC, priority DESC, id DESC` 排序，新任务出现在对应位置。
- 统计缓存刚被删掉，会重新 `COUNT`，总数/未完成 +1。
- 下一次刷新统计才会显示「Redis 命中」。

> 前端没有把新对象直接塞进 `list`，而是重新查。
> 这样最稳：页面显示的一定是数据库里的真实结果。

## 九、3 个常见坑

| 现象 | 原因 |
|---|---|
| 保存没反应 | 表单校验没过，看标题下方红字 |
| `code=400` 但 HTTP 200 | 业务失败看 body 的 `code`，不是 Status |
| 新增后统计没变 | `clearStatsCache` 没执行，或 Redis 挂了 |
